# Canonical customizations

Esta carpeta es la única fuente versionada de las definiciones del proyecto.
La extensión construye desde aquí los formatos que necesita cada IDE:

- `agents/`: agentes de Devin que se convierten en workflows globales de
  Windsurf.
- `skills/`: skills compartidas por Devin y Windsurf.
- `workflows/`: workflows adicionales de Windsurf.
- `rules/`: reglas globales de Windsurf.
