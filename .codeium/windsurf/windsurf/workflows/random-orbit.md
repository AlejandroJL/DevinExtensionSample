# Random Orbit

Workflow experimental usado para comprobar que una nueva versión de la
extensión se descarga, se instala y expone correctamente sus definiciones.

## Comportamiento

1. Resume brevemente la tarea recibida.
2. Propón una observación o alternativa creativa relacionada con la tarea.
3. Separa claramente los hechos de las ideas exploratorias.
4. No ejecutes acciones destructivas ni modifiques archivos salvo que el
   usuario lo solicite de forma explícita.

Este workflow existe principalmente como marcador visible de la versión de prueba.
